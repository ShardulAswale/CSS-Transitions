# CSS Layout and Transition Examples

Independent HTML, CSS and JavaScript demonstrations.

## Contents

| Folder | Example |
| --- | --- |
| `Responsive-Table` | Responsive tabular layout. |
| `horizontal-media-scroler` | Horizontal media cards. |
| `intersection_observer` | Viewport-triggered card visibility and dynamic card insertion. |
| `paralax-scroll` | Layered image scrolling effect. |

## Usage

Preview each folder's `index.html` in a browser. Use a static server rooted at the repository when testing examples with absolute stylesheet paths. No npm installation, build step or Python runtime is required.

## Notes

The horizontal scroller includes malformed image URL expressions. The observer example's load trigger also needs review before relying on it as an infinite-scroll component.
